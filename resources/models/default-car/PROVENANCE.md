# Default vehicle

Kenney Car Kit 3.1, sedan.obj, sedan.mtl and Textures/colormap.png.
Author: Kenney (https://kenney.nl/assets/car-kit). License: CC0; original notice
retained as License.txt. Archive obtained from the author's OpenGameArt posting:
https://opengameart.org/sites/default/files/kenney_car-kit_3.1.zip
The source OBJ/MTL contained literal escaped CRLF sequences; these were normalized
to line endings for import. No model geometry or texture artwork was replaced.

`sedan.preview.json` is a presentation derivative generated on 3 November 2026
with `CarMesh::load(sedan.obj).toJson()` from the native C++ importer. It includes
normalized geometry, sampled face colors and wheel pivots/tags, under the same
CC0 asset notice. Regenerate it when the source mesh/importer changes. It does
not define physics or collision geometry.
