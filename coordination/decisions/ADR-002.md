# ADR-002: Native product and optional showcase branches

3 November 2026. The user requested repository cleanup, completion reconciliation
and an optional web branch showcasing the engine while following the native plan.

`platform/native` is the primary C++/Qt product. `showcase/web` contains an optional
browser client that delegates to the same C++ controller/worker executable and
its paced clock. The HTTP edge contains no physics or autonomous clock. It runs
an independent showcase experiment, rather than attaching to an existing Qt
window. Native C++ source is shared; browser work stays on the showcase branch.

The delivered native Qt/software-3D workflow and early web adapter are valid
product slices before the broader esmini/MPC/replay release gate. WEB-00 and
CLEAN-00 can be manually reconciled against their actual accepted behavior and
path-specific evidence without pretending DEMO-00's larger release dependencies
are implemented. Preserve those original gates and their unfinished scope.
Manual delivery is not a fabricated independent provider review or a silent
integration of old candidate branches.

Completed tasks are recorded in completions.json and the local task database.
The control integration checkout must start future work from the verified native
platform snapshot, rather than its historical pre-desktop baseline. Preserve the
old branch/attempt commits and dirty work; stale candidates need rebasing and
fresh validation before they can be accepted against the new platform baseline.

Existing canonical project hashes and protocol vectors remain unchanged. Browser
project switching/download/import preserve original JSON numeric representations;
editable drafts use native validation/rehashing. Asset presentation does not own
physics. Full recording/replay, external world adapters, tracking/MPC, installer
and container release gates remain open as documented in PLATFORM_STATUS.md.
